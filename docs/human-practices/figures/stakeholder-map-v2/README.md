## Reasoning

This map groups recorded relationships by the question each group helped the team address. It does not preserve an assumed linear route from lab to community, score power/interest without data, or imply clinical readiness. Solid connections mean recorded engagement, including unsuccessful collaboration; dashed connections mean gaps. Spatial positions do not rank importance or influence. The center includes research, choices, communication and everyday support so that workbook/app feedback is not represented as validation of RNA editing.
