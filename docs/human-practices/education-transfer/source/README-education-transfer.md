# BioSphere: retained B map, local revision

The entry remains `education-transfer-map.html` in this original project directory. This revision derives the geographic renderer and region hit testing directly from that file; it is not the dropdown-only replacement project.

## Preview

From this directory:

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

Open `http://127.0.0.1:8769/education-transfer-map.html`. Use another free port if 8769 is occupied. The page also uses classic local scripts rather than requiring a bundler. No external fonts, CDN, model service, uploads, or account are required.

Select a source card or drag it onto a map region/label. Map target labels and source controls are native buttons, with a target selector as an additional accessible alternative. Tab/Enter/Space work through native controls. Pan the map by dragging; use zoom and reset buttons. On touch devices, tap a source and target. Page scrolling is available; Ctrl/Command + wheel zooms the map. After selecting a different target, the original B-style DNA loading overlay runs, then opens `education-transfer-report.html?source=...&target=...`. The report is a separate page containing all six domains and reference outcomes. Back to map retains the route through URL parameters, including after refresh. Reverse route opens the inverse report. Cancel/Escape returns to the map; Open report now skips the animation. Reduced motion uses an 80 ms handoff.

This JSON is newly reconstructed from the local PDFs, rather than claimed to be that missing earlier export.

The six domains retain curriculum and examination scores separately, including ranges and elective qualifications. Each record identifies PDF page and report column. Seventy-six reference outcomes are transcribed from the English framework, with domain, level and page references. No per-outcome curriculum mapping is inferred. Japan + AP remains a single combined study configuration. iAL and HKDSE are separate configurations anchored in Hong Kong; unsupported Macau scoring from the old prototype has been removed.

The interface distinguishes source excerpts from notes generated by range comparison. Original prototype compatibility values, ability radar charts, adaptation durations and unsupported descriptions have been removed. The report is preliminary team document analysis, not an independently validated audit or a prediction of student performance. Current external syllabus editions have not been independently rechecked.

## Verification and limits

The checks cover loading progression/cancellation/Escape/skip/restart/reduced-motion timing, report-page rendering without map dependencies, route URLs/back/reverse links, map/report separation, and all 12 directed routes, route reversal, same/unknown configuration rejection, score-range handling, the 76-outcome catalog, filters, JSON/browser-data parity, and real local D3 topology/hit testing at 358, 640 and 1000 px canvas widths. The map test uses a recording canvas stub; it is not a screenshot or browser-layout test. Static checks also verify local resource paths, unique HTML IDs, English interface strings and source-document hashes.

Browser visual verification remains pending: the browser plugin failed to load a signed local component, and the available browser rejected `file://` navigation. No attempt was made to bypass the browser policy. Review the local HTTP preview manually for exact spacing, keyboard focus, touch behavior and drag feedback in your browser before publication.

No deployment, push, merge, domain registration or new hosted Site was performed.

## Reading hierarchy revision

The map now gives the operation once, uses shorter curriculum names, and places the alternative target control behind one disclosure. Scope and collaboration information is consolidated rather than repeated beside every action.

The report begins with the source-to-target route and a six-row table showing curriculum and examination depths side by side. One selected domain supplies a plain-language explanation and concise source/target context. Original analysis and reference learning goals are closed by default; filters appear only inside the selected domain's optional learning panel. The Sources & scope dialog consolidates documents, scoring, limitations and structured-data download. Raw evidence, scoring ranges, learning outcomes, loading and page navigation are unchanged.

`education-copy.js` contains concise English display paraphrases, with the original source excerpts retained in the evidence library and available on demand. The table counts domains with differing reported ranges; this is not a measure of student ability or a transfer-success metric.
